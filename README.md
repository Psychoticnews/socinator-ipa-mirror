# socinator-ipa-mirror (private)

Release assets only: phone-app packages (IPAs) that are too big for git (>100 MB) and that we cannot afford to lose.
Each IPA is a release asset; its source URL, size and sha256 are recorded in `shared/ipas/MANIFEST.json` in the main Socinator repo.

- `neofreebird-v7.0.0-x12.28.1`: orionblur/NeoFreeBird v7.0.0 (X 12.28.1) - the build whose in-app web login signs in inside LiveContainer.
